<h1>Machine Learning University Project</h1>
<p>This is my group machine learning project where we create a movie recommendation system based on the user preffered genres an 
what kind of movies the user like. The system was trained using movie lens dataset <a href="https://grouplens.org/datasets/movielens/32m/">here</a>
and the system was trained using SVD to create matrix factorization.
This project can be access through streamlit website <a href="https://ml-project-recommender-kel5.streamlit.app/">here</a>
This movie recommendation system also uses The Movie Database (TMDB) API to shop movie poster and synopsis to give user more information about the movie. 
</p>
